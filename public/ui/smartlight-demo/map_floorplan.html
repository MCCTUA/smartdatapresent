Implementation rule: Floor plan is a separate renderer from Leaflet/OSM and must not depend on uploaded blueprint/image files. It adds Building/Floor/position context, but it must reuse the same scoped customer, zone, tag, device, lot, issue, action, and table contracts as maps.html. Use the Building -> Floor -> Zone -> Tag -> Device section structure from the scoped device list. Lot is the inventory/commercial source for devices; floor/zone/tag is the operational placement layer. If no indoor x/y exists, render Auto Layout by Floor -> Zone -> Lot -> Device ID. MAP mode continues to use lat/lng and does not require building/floor, but MAP still shows Zone/Tag.
